# mugi-daily

むーちゃん（Muse）の日替わりアバター画像と、その日のテーマを置く公開リポジトリ。
iPhone の Scriptable ウィジェットがここを読みに来ます。毎朝5時に むーちゃん が自動更新します。

## ファイル

- `today.b64` — その日のアバター画像（PNG 256px を Base64 化したテキスト。GitHub 連携の制約で画像をテキスト形式で置いています）
- `today.json` — 日付・記念日名・意匠・ひとこと
- `widget.js` — Scriptable 用ウィジェット本体（むーちゃん + AUD/JPY レート + ミニチャート）

## ウィジェットの入れ方（iPhone）

1. App Store で「Scriptable」（無料）を入れる
2. Scriptable を開き、右上の「+」で新規スクリプトを作り、`widget.js` の中身を全部貼り付ける（名前は「むーちゃん」など）
3. スクリプトを1回実行して、プレビューが出ることを確認する
4. ホーム画面を長押し →「+」→ Scriptable → 小サイズを追加 → 追加されたウィジェットをタップして、スクリプトに手順2のものを選ぶ

更新間隔は iOS が決めるため、レートは目安15分〜1時間おきに更新されます（秒単位のリアルタイムではありません）。
